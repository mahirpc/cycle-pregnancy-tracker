# Cycle & Pregnancy Tracker

A static, GitHub Pages-ready website built from the provided requirements and reference data.

## What is included
- Cycle tracking dashboard
- Pregnancy tracking dashboard
- Daily journal
- Basic local storage
- JSON export/import
- Settings and theme toggle
- Offline-friendly service worker

## How to run locally
Open `index.html` in a browser or serve the folder with any static web server.

## How to deploy to GitHub Pages
1. Create a GitHub repository.
2. Upload all files in this folder to the repository root.
3. In repository settings, enable GitHub Pages from the root branch/folder.
4. Wait for the Pages URL to become active.

## Notes
- No backend is required.
- All data stays in the browser storage on the user's device.
- The app uses the shipped JSON files in `data/`.
