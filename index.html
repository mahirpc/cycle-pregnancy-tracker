Storage note

Everything stays on this device in browser storage. Browser storage is not encrypted at rest by default, so local app-lock is a convenience feature rather than full device-level security.

The app uses the shipped reference data from the provided cycle and pregnancy datasets and can run as a static site on GitHub Pages.
